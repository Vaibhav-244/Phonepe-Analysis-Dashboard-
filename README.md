📊 PhonePe Analysis Dashboard

An interactive "PhonePe Transaction Analysis Dashboard" developed to analyze transaction performance, transaction value, user activity, and time-based transaction patterns. The project provides a clear view of business performance through interactive KPIs, charts, and comparative analysis.

🔍 Key Analysis

* Total Transactions – Overall transaction volume and performance.
* Total Transaction Value – Analysis of the monetary value processed.
* Total Users – User activity and overall customer base analysis.
* Weekend vs Weekday Analysis – Comparison of transaction value between weekends and weekdays.
* Transaction Trends – Analysis of transaction performance across different time periods.
* User & Transaction Insights – Identification of patterns and trends that can support business decision-making.

📈 Dashboard Highlights

* KPI cards for major business metrics
* Interactive charts and visualizations
* Weekend vs weekday transaction comparison
* Transaction value and volume trends
* User activity analysis
* Business-focused insights for performance monitoring

🛠️ Tools & Technologies

Excel / Power BI | Data Cleaning | Data Analysis | Data Visualization | Dashboard Development**

🎯 Objective

The objective of this project is to transform raw PhonePe transaction data into an interactive and management-friendly dashboard that makes important business metrics easier to understand and helps identify transaction and user behavior patterns.

This project demonstrates practical skills in Data Analytics, Business Intelligence, Dashboard Design, Data Visualization, and Business Insights Generation.
